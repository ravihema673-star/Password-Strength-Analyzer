Password Strength Analyzer

About the Project

I developed this project using Python to check how strong a password is. The program takes a password from the user and checks different conditions to find out whether it is Weak, Medium, or Strong.

What Does This Project Do?

- Checks the length of the password.
- Checks whether uppercase and lowercase letters are present.
- Checks for numbers and special characters.
- Identifies some commonly used passwords.
- Displays the password strength.
- Gives suggestions to make the password stronger.

Tools Used

- Python
- Visual Studio Code

How to Run the Project

1. Download the project files.
2. Open the folder in VS Code.
3. Open the terminal.
4. Run this command:

python Password_analyzer.py

5. Enter a sample password and check the result.

Project Files

- "password_analyzer.py" – Contains the Python code.
- "screenshots/" – Contains the output screenshot.
- "README.md" – Contains the project details.

Output

The program displays three types of password strength:

- Weak
- Medium
- Strong

It also provides suggestions whenever the entered password needs improvement.
